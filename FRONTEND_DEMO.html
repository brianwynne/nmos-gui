💻 Key Code Changes

1. Protocol Selector (HTML)

<div class="form-group"> <label for="nodeProtocol">Protocol</label> <select id="nodeProtocol" name="nodeProtocol"> <option value="nmos">NMOS (IS-04/IS-05)</option> <option value="aes67">AES67 (SAP/SDP)</option> </select> </div>

2. Protocol Toggle Logic (JavaScript)

handleProtocolChange(protocol) { if (protocol === 'nmos') { // Show NMOS fields, hide AES67 fields nmosFields.forEach(el => el.style.display = 'block'); aes67Fields.forEach(el => el.style.display = 'none'); } else if (protocol === 'aes67') { // Show AES67 fields, hide NMOS fields nmosFields.forEach(el => el.style.display = 'none'); aes67Fields.forEach(el => el.style.display = 'block'); } }

3. Client Factory Usage

// Automatically creates the right client based on protocol const client = await ClientFactory.createClient(node); // Works for both NMOS and AES67: await client.initialize(); const senders = await client.getSenders(); const receivers = await client.getReceivers();

⚙️ How It Works

User Flow:

  1. User clicks "Add Node" button
  2. Modal opens with Protocol selector
  3. User selects either NMOS or AES67
  4. Form fields dynamically update based on selection
  5. User enters protocol-specific details
  6. ClientFactory creates appropriate client
  7. Node is saved with protocol field
  8. Protocol badge appears in node dropdowns
